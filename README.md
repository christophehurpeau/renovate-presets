# renovate-presets

- `default.json` (`github>christophehurpeau/renovate-presets`): every repository. Partly generated by `generate-config.json.js` from `pob-dependencies`.
- `expo.json` (`github>christophehurpeau/renovate-presets:expo`): repositories with an Expo app, added by pob. Disables the packages whose versions the Expo SDK pins, which `expo install --fix` updates with the SDK, and `nativewind` / `react-native-css`, whose versions alouette's peer dependencies pin (the alouette repository re-enables them). Generated by `pnpm run generate:expo` from Expo's API (bundled native modules and related packages of the latest SDKs); the weekly `expo-check` workflow fails when it is stale.
